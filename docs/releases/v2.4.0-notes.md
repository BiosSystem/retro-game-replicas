# BiosSystem Neon Arcade v2.4.0

## Highlights

- Build original four-channel music with the Chiptune Tracker Studio, FM patch controls, `.neonseq` import and export, offline WAV rendering, and persisted cabinet BGM assignments.
- Create generated cabinet side art, marquees, and control-panel treatments with the Vector Decal Workshop, `.neonart` import and export, symmetry tools, bounded undo history, and live 2.5D cabinet previews.
- Preserve and share score runs as P-256-signed `.neonproof` records, display verified-score badges, exchange bounded proof records directly with connected peers, and watch saved runs in the spectator overlay.

## Architecture

The release keeps game rules, scoring, and asset generation local and deterministic. Tracker, decal, replay, and proof features are loaded only when requested so the cabinet boot path stays compact. Direct peer proof exchange runs only across an already approved WebRTC connection and does not require a central leaderboard service.

Proof signatures establish integrity and the ownership of a signed replay record. Use the replay viewer to inspect a run locally. Keep peer proof exchange opt-in through the existing direct connection flow.
